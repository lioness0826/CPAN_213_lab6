# Redux Todo App

This project was created for **CPAN213 - Mobile Development** (Fall 2025, Lab #06).  
It demonstrates the use of **Redux Toolkit** and **React Native** for state management.

---

##  Prerequisites

Make sure you have installed:
- Node.js (v18 or higher)
- npm 
- Android Studio / Emulator (or a physical device)
- React Native CLI

---

## Setup Instructions

1. **Clone the repository**
   ```bash
   git clone gitlink
   cd ReduxTodoApp

2. **install dependancies**
   npm install

3. **run app**
   npx react-native run-android (for android)
   npx react-native run-ios (for ios)

Features
- Add new todos
- Mark todos as completed
- View all todos in a list
- Redux DevTools integration for debugging
- State tree visualization in Chrome
